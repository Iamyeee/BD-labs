# Звіт до лабораторної роботи №3

**Тема:** Маніпулювання даними SQL (OLTP: `SELECT`, `INSERT`, `UPDATE`, `DELETE`)  
**База даних:** `shop_db` (PostgreSQL 19, pgAdmin 4)  
**SQL-скрипт:** `dml_lab3.sql`

## Опис виконаних запитів

### 1. Вставка даних (`INSERT INTO`)
- **Мета:** Заповнити таблиці (`categories`, `products`, `customers`, `orders`, `order_items`, `payments`) тестовими даними (по 4–5 рядків у таблицях) та перевірити роботу схеми.
- **Очікуваний результат:** Нові рядки додаються у таблиці без помилок; при повторному запуску спрацьовує обмеження `PRIMARY KEY`.
- **Чи вдався:** Так, початкове наповнення пройшло успішно; при повторному запуску з'явилася помилка `23505` (дубль `category_id = 1`), що підтвердило наявність записів і захист первинного ключа.

### 2. Вибірка даних (`SELECT` та фільтрація через `WHERE`)
- **Мета:** Переглянути дані у таблицях і відібрати конкретні записи за умовами (`price > 20000`, `shipping_address LIKE '%Київ%'`, `total_amount > 25000`) з вибором потрібних стовпців.
- **Очікуваний результат:** Повертаються лише ті рядки, які відповідають умові у `WHERE`.
- **Чи вдався:** Так, запити повернули потрібні записи (зокрема товари дорожче `20000` у `Data Output`).

### 3. Оновлення даних (`UPDATE ... SET ... WHERE`)
- **Мета:** Оновити статус замовлення `order_id = 502` на `'paid'` та статус оплати для цього замовлення на `'completed'` з обов'язковою перевіркою через `SELECT`.
- **Очікуваний результат:** Змінюється лише запис з `order_id = 502` та пов'язаний платіж, інші рядки не зачіпаються.
- **Чи вдався:** Так, контрольний `SELECT` після `UPDATE` показав оновлені статуси.

### 4. Видалення даних (`DELETE FROM ... WHERE`)
- **Мета:** Безпечно видалити запис платежу з `payment_id = 904` у таблиці `payments` і перевірити результат через `SELECT`.
- **Очікуваний результат:** Рядок з `payment_id = 904` видаляється, а повторний `SELECT * FROM payments WHERE payment_id = 904;` повертає 0 рядків.
- **Чи вдався:** Так, повторний `SELECT` повернув `0` рядків (`Total rows: 0`).

## Висновок
Відпрацював базові OLTP-операції (`INSERT`, `SELECT`, `UPDATE`, `DELETE`) у PostgreSQL. Переконався, що умова `WHERE` та попередня/подальша перевірка через `SELECT` дозволяють безпечно змінювати й видаляти потрібні записи без ризику пошкодити всю таблицю.
