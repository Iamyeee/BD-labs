# Лабораторна робота №3

**Тема:** Робота з INSERT, SELECT, UPDATE, DELETE у PostgreSQL  
**База даних:** `shop_db` (pgAdmin 4)

## Що зроблено

1. **INSERT** — додав тестові записи в усі таблиці (`categories`, `products`, `customers`, `orders`, `order_items`, `payments`). При повторному запуску вибило помилку `23505` (дубль `category_id = 1`), бо дані вже були в базі.
2. **SELECT** — перевірив вміст таблиць і зробив вибірки з умовою `WHERE`:
   - товари дорожче `20000`;
   - клієнти з Києва (`LIKE '%Київ%'`);
   - замовлення на суму понад `25000`.
3. **UPDATE** — змінив статус замовлення `order_id = 502` на `'paid'`, а статус його оплати на `'completed'`. Перевірив через `SELECT`, що зміни збереглися.
4. **DELETE** — видалив запис із `payment_id = 904` у таблиці `payments` (з умовою `WHERE payment_id = 904`). Повторний `SELECT` повернув 0 рядків.

## Висновок
Відпрацював базові запити `INSERT`, `SELECT`, `UPDATE` і `DELETE` в PostgreSQL. Перевірив, що при використанні `WHERE` змінюються та видаляються тільки потрібні рядки, а не вся таблиця.
