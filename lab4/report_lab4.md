# Лабораторна робота №4

**Тема:** Аналітичні SQL-запити (OLAP: агрегація, `GROUP BY`, `HAVING`, `JOIN`, підзапити)
**База даних:** `shop_db` (PostgreSQL, pgAdmin 4)
**Скрипт:** `olap_lab4.sql`

## Що зроблено

1. **Базова агрегація** — порахував кількість товарів, мінімальну, максимальну та середню ціну (`COUNT`, `MIN`, `MAX`, `AVG`, `ROUND`).
2. **Групування (`GROUP BY`)** — згрупував замовлення за статусом (кількість і сума) та порахував кількість замовлень по кожному клієнту.
3. **Фільтрація груп (`HAVING`)** — залишив тільки ті статуси замовлень, загальна сума яких більша за `25000`.
4. **Об'єднання таблиць (`JOIN`)** — використав `INNER JOIN` для зв'язку замовлень із клієнтами та `LEFT JOIN` для виводу всіх клієнтів і всіх категорій з товарами (навіть якщо збігів немає).
5. **Підзапити** — застосував підзапити у `WHERE` (товари дорожчі за середню ціну), у `SELECT` (кількість замовлень на клієнта) та у `HAVING` (категорії із середньою ціною вище за загальну середню).

## Висновок
Перевірив аналітичні запити в PostgreSQL на базі `shop_db`: навчився рахувати зведені показники, групувати дані, фільтрувати групи через `HAVING`, об'єднувати таблиці через `JOIN` та будувати підзапити.
